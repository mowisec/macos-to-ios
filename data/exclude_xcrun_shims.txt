# The 95 xcrun shims in /usr/bin, excluded BY PATH.
#
# This is all that survives of the old data/blocklist_ios.txt (retired
# 2026-08-31, archived as measurements/retired_blocklist_ios.txt). It is kept
# because it is the one part of that list that was identified by MEASUREMENT
# rather than by inference, and because removing it actively breaks the tools
# it looks like it is blocking.
#
# What these are: /usr/bin hard-links ONE inode under 78 names, plus a few
# more, whose entire body is a call to xcselect_invoke_xcrun -- look up the
# active Xcode and re-exec into it. There is no Xcode on the phone, so they
# achieve nothing, and on iOS they do not merely fail, they are SIGKILLed
# (EXC_ARM_PAC_FAIL, 78 of the 83 kills in the 2026-08-31 probe).
#
# Why BY PATH and not by name: the names collide with the REAL tools from the
# Xcode toolchain, which do port and do work. otool IS llvm-otool, nm IS
# llvm-nm, objdump IS llvm-objdump. A bare `otool` line here would drop the
# real one too. machomorph matches a pattern containing '/' against the whole
# path, so these hit only the shim.
#
# When both sides are aliases the /usr/bin scan runs first and wins, which is
# how bin/otool, bin/nm, bin/objdump, bin/dwarfdump, bin/size and bin/c++filt
# came to be symlinks to DeRez in an earlier build.
#
# Identified by symbol, not by hand: every binary importing
# _xcselect_invoke_xcrun. Reproduce with machomorph's imports_by_library().
